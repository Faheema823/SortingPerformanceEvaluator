# Sorting Algorithm Performance Evaluation

## University of Colombo - Faculty of Technology
### Department of ICT
**Course Code:** IC4302 - Programming III  
**Project:** Java Application for Sorting Algorithm Performance Evaluation  

---

## Overview
This group assignment application is developed as part of the **IC4302 - Programming III** course requirements at the University of Colombo. The application allows users to upload a dataset in `.csv` format, select a numeric column, apply multiple sorting algorithms, and evaluate their execution performance in real-time via a clean graphical user interface (GUI).

---

## Features
* **CSV Dataset Upload:** Import custom datasets (such as those from Kaggle) and dynamically load available columns.
* **Numeric Column Filtering:** Select specific numeric columns for sorting.
* **Sorting Algorithms Implementation:** Fully implemented sorting algorithms optimized for performance:
  * Insertion Sort
  * Shell Sort
  * Merge Sort
  * Quick Sort
  * Heap Sort
* **Performance Evaluation & Benchmarking:** Measures exact execution times down to the nanosecond/millisecond.
* **Best Algorithm Highlight:** Automatically identifies and highlights the best-performing algorithm with the shortest execution time on a dedicated summary panel.
* **Graphical User Interface (GUI):** Built using Java Swing for an interactive and user-friendly experience.
